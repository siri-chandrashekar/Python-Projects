# Tic-Tac-Toe

A simple command-line Tic-Tac-Toe game built with Python.

## Features

- Play as `X` against a computer opponent
- Uses the minimax algorithm for the computer's moves
- Validates invalid or already-used positions

## How to Run

1. Open a terminal in this folder.
2. Run:

```bash
python main.py
```

## Controls

- Enter a number from `1` to `9` to place your move
- Positions go left to right, top to bottom

Example layout:

```text
1 | 2 | 3
--+---+--
4 | 5 | 6
--+---+--
7 | 8 | 9
```

## Notes

- You play as `X`
- The computer plays as `O`
