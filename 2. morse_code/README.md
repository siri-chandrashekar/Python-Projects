# Morse Code Converter

A simple Python terminal app that converts normal text into Morse code.

## How to Run

```bash
python main.py
```

## Features

- Converts letters, numbers, and some punctuation into Morse code
- Replaces spaces with `/`
- Lets you continue converting multiple messages in one run

## Example

Input:

```text
HELLO WORLD
```

Output:

```text
.... . .-.. .-.. --- / .-- --- .-. .-.. -..
```
