# BrewFinder

BrewFinder is a modern Next.js app for discovering breweries by city and brewery type using the Open Brewery DB API.

## Features

- Search breweries by city
- Filter results by brewery type
- Browse paginated results
- View brewery websites when available
- Clean loading, empty, and error states

## Tech Stack

- Next.js
- React
- Tailwind CSS
- Open Brewery DB API

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Notes

- Brewery data is provided by the Open Brewery DB API.
- This project was built as a frontend learning project focused on search UX, state handling, and polished UI presentation.
