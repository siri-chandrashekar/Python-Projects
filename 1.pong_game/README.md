# Pong Game

A simple two-player Pong game built with Python's `turtle` module.

## Controls

- Right paddle: `Up` and `Down`
- Left paddle: `W` and `S`

## How to Run

```bash
python pong_game.py
```

## Project Files

- `pong_game.py`: main game loop
- `paddle.py`: paddle behavior
- `ball.py`: ball movement and bounce logic
- `scoreboard.py`: score display
- `centerline.py`: dashed center line
