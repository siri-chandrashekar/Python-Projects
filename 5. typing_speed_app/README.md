# Typing Speed Test

A simple Python Tkinter app that lets you test your typing speed and accuracy.

## Features

- Random sample text each round
- 60-second typing timer
- WPM calculation
- Accuracy calculation
- Reset button to start again

## Requirements

- Python 3
- Tkinter
- No extra packages needed

## How to Run

1. Save the file as `main.py`
2. Open a terminal in the project folder
3. Run:

```bash
python main.py
```

## How It Works

- A sample sentence is shown on the screen
- Start typing in the text box
- The timer begins automatically when you type
- When time is up, click **Check Speed** to see your result
- Use **Reset** to try again
