# Dangerous Writing App

A fun CustomTkinter app that forces you to keep writing. Stop typing for 5 seconds, and everything disappears.

## How It Works

- Type anything in the text box.
- Timer resets to 5 seconds on every key press.
- Stop typing and countdown continues.
- At 0 seconds, all text is deleted.
- Keep writing to stay safe.

## Features

- Dark themed interface
- Real-time countdown timer
- Warning color change when time is low
- Instant text deletion when time reaches zero

## Requirements

- Python 3.x
- customtkinter

Install dependency:

```bash
pip install customtkinter
```

## Quick Start

1. Open a terminal in this folder.
2. Run:

```bash
python main.py
```
